<center><h2>No se que jugar</h2></center>

## Dominio elegido
### videojuegos
>Elegimos este dominio porque es una situacion a la que nos hemos enfrentado los miembros del equipo: No poder decidir que jugar a continuacion. 

## Problema que resuelve
Con la enorme cantidad de videojuegos disponibles hoy en día, muchos usuarios no saben qué jugar a continuación y terminan invirtiendo más tiempo buscando uno que jugando. El sistema busca facilitar esa decisión, recomendando títulos según las categorías, géneros o juegos que el usuario ya conoce o le gustan.

## Usuario objetivo
Un trabajador de 32 años que termina su jornada y quiere jugar algo nuevo, pero no sabe qué elegir y no quiere perder el tiempo buscando.


## 5 funcionalidades iniciales
1. Búsqueda por palabras clave/tags
2. Recomendación aleatoria / "Sorprendeme"
3. Juegos relacionados ("si te gustó este, probá este otro")
4. Sistema de valoración/ranking
5. Mostrar informacion
