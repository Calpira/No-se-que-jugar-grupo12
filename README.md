¿Tenés miles de opciones disponibles pero terminás pasando más tiempo buscando qué jugar que jugando? 

**No sé qué jugar** es un sistema de recomendación por consola desarrollado en Python que ayuda a decidir qué título elegir a continuación sobre un catálogo real de **16.678 videojuegos**, aplicando distintas estructuras de datos para optimizar cada tipo de búsqueda.


## Cómo ejecutar

> 1. Clonar el repositorio
> 2. Ejecutar: python main.py

## Funcionalidades del Menú Principal

1. **Búsqueda por etiquetas:** Permite ingresar uno o más tags separados por coma y devuelve el Top 10 de juegos más relevantes (ponderando las coincidencias de etiquetas junto con el rating de cada título).
2. **Búsqueda por título:** Localiza un juego específico de forma rápida y ofrece la posibilidad de consultar juegos similares.
3. **Sorprendeme!:** Elige un juego al azar del catálogo completo para resolver la indecisión cuando no hay filtros definidos.
4. **Explorar categorías:** Muestra la jerarquía de géneros y subgéneros, sirviendo como guía rápida de etiquetas disponibles para buscar.
5. **Quiénes somos:** Presenta al equipo de desarrollo y el contexto académico del trabajo práctico.
6. **Salir del Programa:** Finaliza la ejecución de la aplicación.
